What is not in these numbers

Karpenter burst capacityUsage-driven and unbounded by design. NodePool ceilings are 160 vCPU infra, 480 app, 128 monitoring — a fully saturated infra pool would add roughly $4,765.44/mo on-demand, or about 43% less on spot.
Inter-AZ data transfer$0.01/GB each way. Cilium ENI mode gives pods real VPC IPs, so cross-AZ pod traffic is billed normally.
Internet egressGit clones and container pulls leaving the NLB. Highly workload-dependent.
RDS / ElastiCache snapshots beyond the free allocation7-day RDS backups are free up to allocated storage; 3 Redis snapshots are small.
gp3-monitoring PVCsThe StorageClass exists but no PVC uses it yet. Prometheus + Loki at, say, 500 GiB with 6000 IOPS and 500 MB/s would add about $70.00/mo.
EKS extended support$0.60/hr instead of $0.10 once 1.35 leaves standard support on 2027-03-27 — that is a $365.00/mo cliff if you do not upgrade.
